✨ Features

- Responsive Design:Looks great on desktops, tablets, and mobile phones.
- Home Section:A brief introduction about who I am and what I do.
- About Me:My background, my journey in the School to Work Program, and what I am currently learning.
- Projects: A showcase of my real-world projects (like my CLI Task Manager and Hostel Application).
- Skills: The technologies and tools I am learning (HTML, CSS, JavaScript, React Native, TypeScript, Git).
- Contact: A way for recruiters, mentors, and peers to reach out to me.
- Resume: A downloadable PDF of my current resume.

 Tech Stack

This project was built from scratch using:

- HTML5: For the structure and content of the web pages.
- CSS3: For styling, layouts, and responsive design.
- JavaScript: For interactivity, DOM manipulation, and dynamic content.
- GitHub Pages:For free, reliable hosting.

 How to Run Locally
If you want to view or test this project on your own machine:

Clone the repository:

bash
git clone https://github.com/FlorenceIradukunda/my-portifolio.git

Navigate into the folder:
bash
cd my-portifolio

Open the project:
Simply double-click index.html to open it in your browser, or use a tool like VS Code's Live Server extension for auto-reloading.
